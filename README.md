# PCB Design Portfolio

A collection of PCB projects I worked on while studying at TUES (ELSYS).

These were academic projects and were primarily intended as PCB design exercises rather than finished products. They cover work in KiCad and Cadence OrCAD, from simple analog boards to larger MCU-based designs.

## Projects

### Implant
Compact BLE sensor concept based around an nRF52811 and AD5941, with impedance and temperature sensing and energy-harvesting/power circuitry.

[Project files](./Implant/)

### DogTracker
Battery-powered ESP32-C3 tracker with GNSS, microSD storage, temperature measurement and associated power-management circuitry.

[Project files](./DogTracker/)

### DS0201v1.1
My first PCB design project. I produced 2-layer and 4-layer versions in Cadence OrCAD and later remade both versions in KiCad.

[Project files](./DS0201v1.1/)

### Analog Front End
Small thermistor measurement board using op-amp signal conditioning and an external ADC.

[Project files](./AFE/)

## Tools

Most of my PCB work has been done in KiCad. I originally learned the PCB design workflow using Cadence OrCAD 10.5 (Capture CIS, Layout and PSpice A/D), and I also have experience using LTspice for circuit simulation.
